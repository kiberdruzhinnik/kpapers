# Russian Hunspell dictionary

These unmodified UTF-8 Hunspell files are from [`wooorm/dictionaries`](https://github.com/wooorm/dictionaries/tree/8cfea406b505e4d7df52d5a19bce525df98c54ab/dictionaries/ru), pinned at commit `8cfea406b505e4d7df52d5a19bce525df98c54ab` (retrieved 2026-11-27).

The upstream README lists `dictionary-ru` as Russian under BSD-3-Clause. The included `LICENSE` contains the dictionary's specific copyright and redistribution terms. The `.aff` file is 71,236 bytes and the `.dic` file is 3,473,191 bytes (3,544,427 bytes total).

The dictionary is loaded locally at runtime; extraction does not download linguistic data. The Rust Hunspell-compatible parser is [`spellbook`](https://crates.io/crates/spellbook) 0.4.2, licensed MPL-2.0.
